## 7. Repo gates (target side)

### Husky pre-commit

```bash
bunx lint-staged

bun run types:check
bun run vars:check
bun run skills:check

STAGED=$(git diff --cached --name-only --diff-filter=ACMR)
if echo "$STAGED" | grep -qE '^(\.claude/skills/.+/SKILL\.md$|scripts/build-skill-registry\.ts$|\.claude/skills/REGISTRY\.md$)'; then
  bun run skills:registry:check || {
    echo ""
    echo "❌ .claude/skills/REGISTRY.md is stale. Fix:"
    echo "   bun run skills:registry && git add .claude/skills/REGISTRY.md"
    exit 1
  }
fi
```

### Husky pre-push

```bash
bun run repo:check
```

(Equivalent to `format:check && lint:check && types:check && vars:check && skills:check && skills:registry:check`.)

**Bypass**: `git commit --no-verify` / `git push --no-verify` — possible but discouraged. Critical Rule #10 in `<framework>/CLAUDE.md` forbids skipping hooks unless explicitly requested.
